type TCoreWebView2CrashReport = class(TObject)

Description

Provides crash signature data captured at the moment of process failure.

CrashReport is nil when the failure did not produce a crash report (normal exit, external kill, launch failure, hang). CrashReport may be nil for certain crash-type failures where no crash report was produced; host apps should always check for null before accessing properties.

<see href="https://learn.microsoft.com/en-us/microsoft-edge/webview2/reference/win32/icorewebview2crashreport">See the ICoreWebView2CrashReport article.)

Public property Initialized : boolean read GetInitialized;

Returns true when the interface implemented by this class is fully initialized.

Public property BaseIntf : ICoreWebView2CrashReport read FBaseIntf;

Returns the interface implemented by this class.

Public property BucketId : wvstring read GetBucketId;

Crash bucket identifier assigned by Microsoft's crash telemetry service. Returned as a 32-character hex string. Empty when no bucket was assigned: crash data was not uploaded to Microsoft's telemetry service (custom crash reporting enabled), or no response was received from the telemetry service (network throttled or unavailable).

Public property CrashReportId : wvstring read GetCrashReportId;

The unique identifier (UUID) for this crash report. Use this to locate the corresponding dump file in `FailureReportFolderPath`.

Public property ExceptionCode : LongWord read GetExceptionCode;

The Windows exception code for the failure, e.g. `0xC0000005` for `STATUS_ACCESS_VIOLATION`. `0` if not available.

Public property FaultOffset : uint64 read GetFaultOffset;

Relative virtual address (RVA) of the faulting instruction within `FaultingModuleName`. `0` if not available.

Public property FaultingModuleName : wvstring read GetFaultingModuleName;

Basename of the module containing the faulting instruction, e.g. `renderer.dll`.

Public property FaultingModuleVersion : wvstring read GetFaultingModuleVersion;

Version of the faulting module, e.g. `128.0.2739.42`.

Public property ReportTime : uint64 read GetReportTime;

Time the crash report was recorded, as a Windows FILETIME value (100-nanosecond intervals since Jan 1 1601 UTC). `0` if unavailable.
